# Deployments

The current deployment of the contract on each network. This table is generated from the project's deployment records at every build of the site, so it always shows the address the site itself uses.

<DeploymentsTable contractName="BillsOfExchange"/>

The source code of each deployment is verified on Etherscan and Blockscout: the explorer links open the verified code, which you can compare with the [source in the repository](https://github.com/bill-of-exchange/bill-of-exchange.github.io/tree/master/smart-contracts/contracts).

:::warning
Test networks are not valid registries for real bills of exchange.
:::
